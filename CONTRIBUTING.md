# Contributing

This repository is published from an internal NVIDIA source and does **not accept external contributions** — pull requests will not be merged.

If you spot a factual error or a dead link in the guide, you are welcome to open an [issue](../../issues) so it can be corrected at the source. For security concerns, follow the disclosure process in [SECURITY.md](SECURITY.md) rather than filing a public issue.
